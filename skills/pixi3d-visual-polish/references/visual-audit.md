# 03 — VISUAL AUDIT INTELLIGENCE

Perform a professional visual audit.

Evaluate:

Composition

- Foreground
- Midground
- Background
- Visual hierarchy
- Focal points
- Negative space
- Scene balance

Depth

- Perspective
- Camera projection
- Occlusion
- Object scale
- Atmospheric perspective
- Ground contact

Geometry

- Silhouette
- Proportions
- Bevels
- Surface details
- Polygon density
- Geometry efficiency

Materials

- Base color
- Roughness
- Metallic response
- Normal maps
- Texture quality
- Material consistency

Lighting

- Key light
- Fill light
- Rim light
- Ambient illumination
- Contact shadows
- Environmental lighting

Visual defects

Detect:

- Floating objects
- Z-fighting
- Clipping
- Incorrect depth
- Texture stretching
- Aliasing
- Shadow artifacts
- Unwanted transparency
- Visual noise
- UI overlap

For every defect provide:

- Evidence
- Severity
- Root cause
- Gameplay impact
- Proposed correction
- Acceptance criteria

Never invent a defect.

# 04 — ART DIRECTION BIBLE

Establish the game's visual identity before making changes.

Supported directions:

- Premium stylized 3D
- Cartoon 3D
- Low-poly
- Toy-like 3D
- Clay style
- Isometric
- Cinematic stylized
- Realistic
- Minimalist

Define:

1. Color palette
2. Shape language
3. Geometry standards
4. Material standards
5. Lighting direction
6. Environment style
7. Character proportions
8. Animation language
9. Camera language
10. VFX language
11. UI system

Create reusable visual standards.

Every new asset must follow the same art direction.

# 05 — WORLD & ENVIRONMENT DESIGN

Design environments with professional production quality.

Environment systems

- Terrain
- Platforms
- Roads
- Buildings
- Rocks
- Vegetation
- Environmental props
- Background layers
- Atmospheric effects

World design

Create:

- Recognizable world identity
- Consistent environmental scale
- Clear navigational paths
- Readable obstacles
- Controlled visual density
- Environmental storytelling

Procedural generation

When required, implement:

- Seeded generation
- Modular environment prefabs
- Reusable asset libraries
- Deterministic placement
- Biome-specific variation
- Collision-aware placement

Procedural generation must preserve gameplay fairness and visual coherence.

# 14 — VISUAL COMPARISON ENGINE

When screenshots are available:

1. Inspect original image.
2. Identify visual weaknesses.
3. Define target appearance.
4. Prioritize corrections.
5. Implement changes.
6. Capture updated screenshot.
7. Compare at equivalent camera, resolution and scene state.
8. Identify regressions.
9. Refine.

Use comparable screenshots.

Evaluate:

- Composition
- Lighting
- Color
- Depth
- Geometry
- Material
- Animation state
- UI

Do not claim improvements that cannot be observed.
